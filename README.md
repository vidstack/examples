# Vidstack Examples

> [!IMPORTANT]
> **These examples are for Vidstack Player, which is in security-only maintenance.** For new projects, start with [Video.js 10](https://videojs.org/docs/framework/html/guides/installation?utm_source=vidstack), where the teams behind Vidstack, Plyr, Media Chrome, and Video.js now focus their work. To move an existing Vidstack project, follow the migration guide for [React](https://videojs.org/docs/framework/react/guides/migrate-from-vidstack?utm_source=vidstack) or [web components and other frameworks](https://videojs.org/docs/framework/html/guides/migrate-from-vidstack?utm_source=vidstack). To migrate with a coding agent, paste the prompt from the guide's AI Quickstart section into it: [React](https://videojs.org/docs/framework/react/guides/migrate-from-vidstack?utm_source=vidstack#ai-quickstart) · [Web components and other frameworks](https://videojs.org/docs/framework/html/guides/migrate-from-vidstack?utm_source=vidstack#ai-quickstart).

This repository is dedicated to showing you how to get started with Vidstack using various
JavaScript frameworks and CSS libraries.

## Local

You can run the examples locally by following these steps:

1. `git clone git@github.com:vidstack/examples.git vidstack-examples`
2. `cd vidstack-examples`
3. `pnpm i`
4. `pnpm start` - launches a process for you to select which example to run.

## Remote (recommended)

Each example has a README which contains an "Open in StackBlitz" link. If you click it, it'll
fork and launch the project in [StackBlitz](https://stackblitz.com). You can run the code, edit it,
and preview it inside their development environment. This is the easiest way to start playing with
the examples.
